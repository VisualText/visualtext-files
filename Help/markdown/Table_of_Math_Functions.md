# Table of Math Functions

NLP++ now features mathematical functions analogous to those provided in C/C++.

| **FUNCTION NAME** | **RETURNS** | **DESCRIPTION** |
| --- | --- | --- |
| [**abs(num_int)**](abs.md) | **INT** | Get the absolute value of a given integer. |
| [**ceiling(num_float)**](ceiling.md) | **INT** | Round a number up to the nearest whole number. Analogous to the ceil function in C/C++. |
| [**factorial(num_int)**](factorial.md) | **INT** | Get the factorial of a non-negative integer. |
| [**floor(num_float)**](floor.md) | **INT** | Round a number down to the nearest whole number. Analogous to the floor function in C/C++. |
| [**log(num_float)**](log.md) | **FLOAT** | Get the natural (base e) logarithm of a number. Analogous to the log function in C/C++. |
| [**logten(num_float)**](logten.md) | **FLOAT** | Get base 10 logarithm of given number. Analogous to log10 function in C/C++. |
| [**mod(num_int1, num_int2)**](mod.md) | **INT** | Get the remainder of dividing one integer by another. |
| [**pow(base_float, exponent_float)**](pow.md) | **FLOAT** | Raise a number to the given power. Analogous to the pow function in C/C++. |
| [**randomint(num_int1, num_int2)**](randomint.md) | **INT** | Get a random integer between two given integers, inclusive. |
| [**round(num_float)**](round.md) | **INT** | Round a number to the nearest whole number, with halfway cases rounding away from zero. Analogous to the round function in C/C++. |
| [**sqrt(num_float)**](sqrt.md) | **FLOAT** | Get the square root of a number. Analogous to the sqrt function in C/C++. |
| [**truncate(num_float)**](truncate.md) | **INT** | Discard the fractional part of a number, rounding toward zero. Analogous to the trunc function in C/C++. |
|   |   |   |
