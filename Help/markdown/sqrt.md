# sqrt

## Purpose

Compute the square root of a number.

## Syntax

```
returnedFlt = sqrt(numFlt)
```

```
returnedFlt - type: float

numFlt - type: float
```

## Returns

The square root of the given number.

## Remarks

Analogous to the sqrt function in C/C++. A negative argument is an error and no value is returned.

## Example

```
@CODE

"output.txt" << sqrt(16) << "\n";

@@CODE
```

```
Outputs:
```

```
4
```
